# Lumen Code 1.1.0 发布资料

源码提交：`7d468055`（标签 `v1.1.0`，发布分支 `release/v1.1.0`）。协议仍为 1.0，线格式没有改变，与此前的 1.0 版互通。商店提交由账号持有人操作，本轮没有代为提交审核。

这一版的内容：接收更快（实测数据和条件见[性能指南](../../docs/guide/04-performance.zh-CN.md) §4.2）、帧率上限跟随屏幕刷新率、手机横拿时扫描界面跟着转、桌面端新默认值。

## 已完成

- [桌面正式版下载](https://github.com/mondaylabsltd/lumen-code/releases/tag/v1.1.0)：Windows、Linux x86_64 / ARM64 由 CI 构建；macOS universal / Apple silicon / Intel 三个 DMG 在本机用 Developer ID 签名并公证后上传。
- Android release APK、AAB 已用原上传密钥签名：版本名 1.1.0，versionCode 4，R8 开启。上传证书 SHA-256 `ca42a513a6b89e8a27b89586bc3a453c51ba3ce17e7cbe243ac5319d813f4dad`，与 1.0.1 相同。
- iOS Release archive 已构建：版本 1.1.0，build 3，内嵌提交 7d46805。
- 网站随 `main` 部署。

## 验证情况

| 平台 | 做了什么 |
|---|---|
| iPhone 15 Pro | 同一份源码的调试版真机实测接收（外接 60 Hz 屏和 MacBook 内置 120 Hz 屏），数据见性能指南；Release archive 只做了构建 |
| Redmi K40 | 签名 release APK 从 1.0.1（versionCode 3）覆盖升级安装，启动、进入接收界面、打开相机正常，无崩溃。**没有测到接收**：测试时手机没有对着屏幕 |
| macOS 桌面 | 本机实测发送（60 Hz 外接屏、120 Hz 内置屏） |
| Windows、Linux 桌面 | CI 构建通过，没有在真机运行 |
| 网站 | 类型检查、单元测试、Playwright（假相机，两种引擎，两种语言）；没有用真实相机实测新的接收逻辑 |

提交 Android 前，建议先在一台 Android 手机上实际收一次文件，并把手机横过来看一眼扫描界面：这部分代码只在 iPhone 上看过效果。

## iOS 导出

```sh
xcodebuild -exportArchive -archivePath src/ios/build/archive/Lumen-1.1.0.xcarchive -exportPath src/ios/build/release/1.1.0 -exportOptionsPlist src/ios/build/export-options-1.1.0.plist -allowProvisioningUpdates
```

1.0.1 时 Xcode 返回过 `PLA Update available`，需要账号持有人先在 Apple Developer 处理待更新协议；这一轮没有重新尝试导出。build 号为 3，同版本再次上传前须增加。
