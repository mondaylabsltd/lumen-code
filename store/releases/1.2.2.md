# Lumen Code 1.2.2 发布资料

源码提交：`5129501`（标签 `v1.2.2`，发布分支 `release/v1.2.2`）。协议仍为 1.0，线格式没有改变，与此前的 1.0 版互通。商店提交由账号持有人操作，本轮没有代为提交审核。

1.2.2 比 1.2.1 多两项：

- 接收时盖住正在读取的码：读得好时在码的位置盖一块深色板，中间显示进度；读得差时变淡，读不出时不盖。相机工具栏的眼睛图标可以关掉，选择会记住。识别框不再随单次拍摄时有时无。变焦按钮只在放大后出现。
- 网站：多摄手机上默认打开后置主摄（S22 的 Chrome 原来给的是超广角）；翻转按钮只在后置主摄和前置主摄之间切换。这一项在 1.2.1 之后已随 `main` 上线，这一版正式写入发布说明。

1.2.0、1.2.1 的内容见各自的发布资料。商店包没有提交过 1.2.0 和 1.2.1，直接用 1.2.2。

## 已完成

- [桌面正式版下载](https://github.com/mondaylabsltd/lumen-code/releases/tag/v1.2.2)：Windows、Linux x86_64 / ARM64 由 CI 构建；macOS universal / Apple silicon / Intel 三个 DMG 在本机用 Developer ID 签名并公证后上传。
- Android release APK、AAB 已用原上传密钥签名：版本名 1.2.2，versionCode 8，R8 开启。上传证书与 1.0.1 相同。
- iOS Release archive 已构建并导出 ipa：版本 1.2.2，build 7，内嵌提交 5129501。
- 网站随 `main` 部署。

## 验证情况

| 平台 | 做了什么 |
|---|---|
| iPhone 15 Pro 应用 | 遮罩：调试版真机连拍，修复稳定性前 16 张里 6 张有识别框和遮罩，修复后 16 张都有（接收 439–458 KB/s）。Release 构建装机后由维护者使用，认可遮罩效果；相册选择的结果没有反馈 |
| Redmi K40 应用 | 带遮罩的签名 release 包已装机；相机画面无法从电脑截取，效果由维护者看，没有反馈 |
| Galaxy S22 应用 | 这一版没有装机 |
| 网站 | 类型检查、单元测试、Playwright（假相机在 WASM 和 JS 两条路径上把文件完整收下）；遮罩开和关用假相机截图看过。稳定性修复之后没有再截图。S22 的 Chrome 上实测过默认主摄和翻转按钮（6 次全部成功） |
| macOS 桌面 | 构建通过；遮罩没有对着码看过 |
| Windows、Linux 桌面 | CI 构建通过，没有在真机运行 |
