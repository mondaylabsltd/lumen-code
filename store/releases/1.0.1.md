## iOS 导出前的一项账号操作

Xcode 返回 `PLA Update available`，随后无法获取 `ltd.mondaylabs.lumencode` 的 App Store 发布描述文件。请由账号持有人先在 Apple Developer 处理待更新协议。现有 archive 可继续使用，无需重编译：

1. 打开 `src/ios/build/archive/Lumen-1.0.1.xcarchive`。
2. 在 Xcode Organizer 选择 **Distribute App → App Store Connect**，使用 MONDAY LABS LTD 团队的自动签名导出或上传。
3. iOS build 为 2；如果同版本已经上传过 build 2，再上传前须增加 build 号并重建。

也可在仓库根目录执行（只导出，不上传）：

```sh
xcodebuild -exportArchive   -archivePath src/ios/build/archive/Lumen-1.0.1.xcarchive   -exportPath src/ios/build/release/1.0.1   -exportOptionsPlist src/ios/build/export-options-1.0.1.plist   -allowProvisioningUpdates
```
