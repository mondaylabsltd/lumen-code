# Notes for app review — 1.0.1

以下英文可直接粘贴进 App Store 的审核备注。Google Play 的“应用访问权限”可说明所有功能无需账号或登录；接收需要另一块屏幕，不是账号访问限制。

```text
Lumen Code transfers files and text from a screen to a phone camera. No account, login or subscription is needed. All functions are available without access restrictions. Receiving requires a second screen displaying a Lumen code.

To test receiving:
1. On a computer, open https://lumencode.link/send, choose the Text tab and type a short message, then tap Send text and confirm the photosensitivity notice.
2. On the phone, open Lumen Code, tap Receive, allow the camera and point it at the computer screen so the whole code is visible.
3. When reception completes, the text opens in a reader and can be copied, saved or shared.

To test sending:
1. Tap Send in the app and choose a file or enter text.
2. Start sending and confirm the photosensitivity notice.
3. On a second camera-equipped device, open https://lumencode.link/recv, open its camera and point it at the phone screen.

Opening a file with Lumen Code on iOS, or sharing a file to Lumen Code on Android, selects that file for sending.

The sending code changes colour up to 60 times a second. The app waits for photosensitivity confirmation before the first playback.

The installed app makes no network connections and collects no data. Camera frames and transferred content are processed locally. The website only needs internet access to load its pages; the file transfer itself does not use a network.

Support: hello@mondaylabs.ltd
Privacy: https://lumencode.link/privacy
Source code (MIT): https://github.com/mondaylabsltd/lumen-code
```

演示视频可在实际上传并确认公开可访问后另行补充；这份可粘贴的备注不含占位链接。
